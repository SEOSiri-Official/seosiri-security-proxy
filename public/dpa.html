SEOSiri Data Processing Addendum (DPA) & Compliance Shield

Effective Date: September 2026 | Jurisdiction: Global (EU GDPR, UK GDPR, California CCPA/CPRA)

1. Data Controller vs. Data Processor

The client website or application acts as the Data Controller. SEOSiri Enterprise Labs acts strictly as an automated Data Processor providing edge security, packet sanitization, and reverse-proxy routing.

2. Clean Traffic In-Memory Non-Retention

All legitimate, unflagged incoming HTTP/HTTPS traffic is proxied through Cloudflare V8 memory isolates with zero persistent logging. IP addresses of innocent end-users are never retained on disk.

3. Cybersecurity Exemption (EU GDPR Recital 49 & CCPA § 1798.145)

In the event of an active threat signature (SQLi, XSS, BOLA/IDOR, Mass Assignment, DDoS), incoming telemetry including source IP, network ASN, and payload fragments is logged under Legitimate Interest for Network Security (EU GDPR Article 6(1)(f) and Recital 49) and California Civil Code § 1798.145(a)(1).

4. 30-Day Automated Data Purge

All incident telemetry is automatically deleted after thirty (30) calendar days. SEOSiri is contractually prohibited from selling, leasing, or using security data for commercial advertising.
